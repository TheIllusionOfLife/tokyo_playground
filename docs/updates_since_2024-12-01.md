# Roblox開発者向け重要アップデート総覧（2024年12月〜2026年3月）

この約16か月間でRobloxプラットフォームは**史上最大規模の変革期**を迎えた。エンジン面ではUnified LightingやSLIMによるビジュアル品質の飛躍、スクリプト面ではLuau新型ソルバーの正式リリースとServer Authorityの導入、経済面ではDevExレート初の引き上げとCreator Rewardsへの移行、そしてプラットフォーム全体では顔認証によるチャット年齢確認の世界的義務化が実施された。クリエイターの年間収益は初めて**15億ドル**を突破し、エンジン技術・AI支援・収益化・安全対策のすべてが同時に大きく前進した期間である。

## 1. エンジン・グラフィックス：Unified LightingとSLIMがビジュアルの新基準を築く

### Occlusion Cullingの全プラットフォーム展開

2024年12月10日にWindows PCで初めてライブ化されたOcclusion Culling（遮蔽カリング）は、他のオブジェクトに隠れた描画を省略することでGPU負荷を大幅に削減する技術である。テスト環境では低スペックAndroid端末のフレームタイムが**約33%改善**し、中央値でも約28%の向上が確認された。2025年1月27日までに全プラットフォームへ展開が完了し、2025年6月23日にはTerrain（地形）の完全サポートも追加された。テストシーンでは描画コール数が708から450へ削減されるなど、開発者がアクションなしで享受できるパフォーマンス改善として大きなインパクトをもたらした。

### Unified Lightingの段階的リリース

Robloxのライティングシステムを根本から刷新するUnified Lightingは、2025年1月21日にStudio Betaとして登場した。従来の`Lighting.Technology`プロパティ（Future / ShadowMap / Voxel）を廃止し、**`LightingStyle`**（RealisticまたはSoft）と**`PrioritizeLightingQuality`**（EnabledまたはDisabled）の2つの新プロパティに置き換えた。これにより全デバイスでのライティングスケーラビリティが向上し、中距離オブジェクトのライティング品質や遠景のシャドウディテールが改善された。2025年7月23日に全エクスペリエンスで正式ライブとなり、既存プロジェクトには自動マイグレーションが適用された（Future → Realistic + Prioritized、ShadowMap → Soft + Prioritized、Voxel → Soft + Disabled）。

なお、2025年9月にはローカルライト（PointLight、SpotLight、SurfaceLight）の最大レンジが**60スタッドから120スタッド**に倍増し、少ない光源で広い空間を照らせるようになった。一方で、Voxelライティングの刷新は2025年末のロードマップから完全に削除された。

### SLIM：スケーラブルなLODシステム

RDC 2025（2025年9月5日）で発表されたSLIM（Scalable Lightweight Interactive Models）は、従来のModel Level of Detailを置き換える新しいLODシステムである。遠距離のアセットを自動でマージ・最適化し、頂点数と描画コール数を大幅に削減しつつメッシュのボリュームを維持する。2025年11月14日にPC/MacでClient Betaが開始され、2026年2月25日に全プラットフォームへ拡大した。GamesBeatの報道では「よりリアルで詳細な世界のレンダリングを可能にするスケーラブルグラフィックス」と評されている。

### Texture Streamingと4Kテクスチャ

2025年12月にTexture Streamingが導入された。デバイスの能力に応じてベースライン品質のテクスチャを優先的に読み込み、その後段階的に高解像度版をストリーミングする仕組みで、2026年1月30日に全プラットフォームのクライアントへロールアウトが完了した。これと連動して**4Kテクスチャレンダリング**が2026年初頭に公開エクスペリエンスで利用可能となり、対応デバイスでは最大4K解像度でのテクスチャ表示が実現した。

### Roblox Studioの大幅なUI刷新

Studioのリボンツールバーが完全に再構築された。2025年8月19日にパブリックベータの詳細が公開され、リボンタブの完全カスタマイズ（プラグインの任意タブへの追加、並べ替え、リネーム）、コンパクト密度オプション、折りたたみ可能なリボン、Robloxグローバルデザインシステムに準拠した新カラーパレット（Light/Darkテーマ）が実装された。2025年11月20日にフルロールアウトが発表され、**2026年1月初旬に旧UIが廃止**されて新UIが標準インターフェースとなった。また、2025年中頃にはNext-Gen Explorerパネルも再構築され、大規模プレイスでのスケーラビリティとパフォーマンスが向上した。

### その他のエンジン・グラフィックス関連アップデート

- **PBR for Avatar Accessories**（2025年8月）：ラフネスとメタルネスを用いた物理ベースレンダリングがアバターアクセサリに適用
- **UIStroke改善**（2025年中頃）：スケーリング対応の太さ、カスタムボーダーアラインメント、無制限ストロークのサポート
- **UI Styling Beta**（2025年中頃）：StylesheetsシステムによりワンクリックでのUI外観変更が可能に
- **Aerodynamic Forces Beta**（2025年春）：物理ベースの飛行・移動のための空力シミュレーション
- **アバターレンダリング最適化**（2025年12月）：FastClusterとLayered Clothingのパフォーマンス改善
- **Windows 7/8.1サポート終了**（2024年12月20日）：StudioがmacOS 10.13と合わせてサポートを廃止

## 2. スクリプト・API：Luau新型ソルバーとServer Authorityが開発体験を変革

### Luau言語の主要アップデート

**2025年11月20日、Luau新型Type Solverが正式リリース**された。これはLuauの型システムを根本から再設計したもので、全ユーザーのnocheckおよびnonstrictモードでデフォルト有効となった。主な新機能は以下の通り。

- **Read-only Table Properties**：テーブルプロパティの読み取り専用アノテーション/推論
- **Better Type Refinements**：変数の型変更の動的追跡
- **Type Functions**：オーバーロードされた演算子のより良い推論と表現力豊かな型シグネチャ
- **Singleton Type改善**：不要な警告の削減
- **緩和されたキャスト規則**：`any`を経由せずのキャストが可能に
- **新Nonstrictモード**：未知のグローバル変数や証明可能なランタイムエラーに焦点を当てた再設計

2025年の間に追加された他の重要なLuau機能として、**`const`キーワード**（再代入を静的に禁止する定数バインディング）、**`vector`ライブラリ**（ネイティブベクター型の組み込みライブラリ）、新しい数学関数（`math.map`、`math.lerp`、`math.isnan`、`math.isinf`、`math.isfinite`）、新しいバッファ関数（`buffer.readbits` / `buffer.writebits`）がある。**Native Code GenerationがAndroidに対応**し、アップバリューやバッファのロード・ストア伝搬などの大規模な最適化も実施された。

**Require-by-String**は2025年5月20日に初期リリースされ、インスタンス参照の代わりに文字列パスでモジュールをrequireできるようになった（例：`require("./Module")`）。2026年1月8日には`@self`エイリアスが追加され、`require("@self/Child")`でカレントスクリプトの子モジュールを参照できるようになった。

### Server Authority：クライアント・サーバー通信の根本的変革

**Server Authority**はRDC 2025で発表され、2025年10月にEarly Access、2025年12月9日にStudio Betaとして公開された。サーバーをすべてのゲームアクションの「唯一の真実のソース」とし、クライアント側の予測とロールバック/リシミュレーションを組み合わせるネットワーキングモデルである。主な構成要素は以下の通り。

- **`RunService:BindToSimulation`**：クライアントとサーバー双方での固定周波数シミュレーションコールバック
- **NextGenerationReplication**：大幅なレプリケーション変更（Server Authority必須）
- **クライアント側予測**：サーバーがミスプレディクションを修正するロールバック機構
- **Flexible Attributes**：ランタイムでのAttribute型変更・追加・削除が可能
- **60+ FPSサポート**：高フレームレートへの完全対応
- **InputAction統合**：プレイヤー入力がInputActionシステム経由でサーバーに転送

これに関連して、**Input Action System**が2025年6月にStudio Betaで登場し、宣言的でクロスプラットフォームな入力バインディングを可能にした。2025年8月にClient Beta、2026年2月に追加更新が行われている。

### AI支援ツールの急速な進化

Roblox AssistantとAIツール群は、この期間中に最も急速に発展した分野の一つである。

**2025年3月**にRoblox Cube 3Dが発表され、テキストプロンプトから数秒で3Dメッシュを生成するMesh Generation APIがAssistant内で利用可能になった（例：`/generate a motorcycle`）。Cube 3Dはオープンソースとしても公開された。

**2025年5月**にオープンソースのStudio MCP（Model Context Protocol）Serverがリリースされ、Claude、Gemini等の外部AIツールからStudioのゲーム構造の探索やスクリプトの読み書きが可能になった。**2025年9月のRDC 2025**ではAssistantのMulti-Step Actions（複数ステップタスクの自動実行、デバッグ、リファクタリング）が発表された。

**2026年2月21日**には外部LLMサポート（BYOK）が追加され、Anthropic、OpenAI、Google GeminiのAPIキーでAssistantを駆動できるようになった。**2026年3月5日**にはMCP Serverがstudioにネイティブで組み込まれ、プレイテスト自動化（仮想マウス/キーボード入力シミュレーション、キャラクターナビゲーション）が可能になった。2026年3月にはさらに`GenerateModelAsync` APIによるテキストからのテクスチャ付き3Dメッシュ生成も追加された。

### 新API・サービスとデバッグツール

新たに追加された主要APIとしては、**Text-to-Speech API**（2025年10月頃に正式リリース、10種のプリセット英語音声）、**Text Generation API**（LLM駆動のNPC対話生成、ベータ）、**Speech-to-Text API**（2025年11月ベータ）がある。

デバッグツールでは、**MicroProfiler**にメモリプロファイリング、フレームグラフ、差分比較機能（2025年中頃）、ネットワークプロファイリングプラグイン（2025年8月25日）が追加され、ネットワークトラフィックグラフや個別ネットワークイベントの詳細分析が可能になった。また**2025年12月**にはOpenGameEvalが公開され、Studio内AIアシスタントのベンチマークを47のテストケースで評価できるようになった。

## 3. マネタイズ・経済：DevExレート初の引き上げと収益化手段の多様化

### DevExレート8.5%引き上げ ― 約6〜8年ぶりの変更

**2025年9月5日のRDC 2025で、DevExレートが1 Earned Robuxあたり$0.0035から$0.0038に引き上げ**られた。これは2017年頃以来の初の引き上げであり、10,000 Earned Robuxの換金額が$35から$38に増加した。カットオフ時点以前に獲得されたRobuxは旧レート、以降に獲得されたものは新レートで換金され、旧レート分が先に消費される仕組みが適用された。Robloxの2025年Q4決算では、この8.5%増が2026年の通年マージンに影響を与えるとの見通しが示された。

### Creator Rewards：Engagement-Based Payoutsの後継

**2025年6月24日に発表、7月24日にライブ化**されたCreator Rewardsプログラムは、従来のEngagement-Based Payouts（Premium Payouts）とCreator Affiliateパイロットプログラムの両方を置き換える新しいクリエイター報酬体系である。2つの要素で構成される。

- **Daily Engagement Rewards**：「Active Spender」（過去60日間に$9.99以上を支出したユーザー）がクリエイターのエクスペリエンスで10分以上プレイすると**5 Robux**が付与（1日あたりユーザー1人につき最初の3エクスペリエンスまで）
- **Audience Expansion Rewards**：新規または復帰ユーザー（60日以上非アクティブ）がプラットフォーム参加後最初の2か月間に行うRobux購入の最初$100に対して**35%のレベニューシェア**

従来はPremiumサブスクライバーのみが対象だったが、新制度では$9.99以上を支出したすべてのユーザーが対象となり、対象プレイヤーベースが大幅に拡大した。

### Paid Access（ローカル通貨対応）と Regional Pricing

**2025年1月31日、Robuxではなく法定通貨でのPaid Access**が開始された。レベニューシェアは価格帯に応じて段階的に設定されている（$9.99で**50%**、$29.99で**60%**、$49.99で**70%**）。従来のRobux経由の約24.5%と比較して大幅に有利な条件となった。

Regional Pricing（地域別価格設定）は段階的に展開された。2025年4月24日にPassesでオプトイン開始、2025年6月9日にアバターアイテム、2025年9月にDeveloper Productsへ拡大し、**2026年3月30日にはすべてのPassesでデフォルト有効**となった。参加エクスペリエンスでは課金ユーザーが**26%増加**したとの報告がある。

### 広告システムの大規模拡張

**Rewarded Video Ads**が2025年4月1日にGoogle Ad Managerとのパートナーシップのもとで正式ローンチした。13歳以上のユーザーが6〜30秒の動画広告視聴と引き換えにゲーム内報酬を得る形式で、完視聴率は**80%以上**（一部エクスペリエンスでは90%以上）、ユーザー好感度は87%と報告された。2025年8月に対象クリエイターが拡大され、2026年2月18日にはすべてのads-eligibleクリエイターに開放された。

**2026年1月6日のCES 2026**では、Homepage Feature（ホームページのフィーチャー広告、CPM課金のクローズドベータ）が発表された。DAU **1.51億人以上**のエントリーポイントであるホームページ上で、動画クリエイティブがインタラクティブな3D環境に変化する新フォーマットである。プログラマティックパートナーもGoogleに加え、Amazon DSP、Liftoff、Index Exchange、Magnite、PubMaticが追加された。

**2026年3月20日**には、**ブランドインテグレーション収益シェアポリシー**が発表された。2027年1月から、ゲーム内のすべてのブランド統合/スポンサーシップ収益に対してRobloxが一定割合を徴収する方針である（具体的な割合は2026年Q2にクリエイターと協議の上決定）。2026年5月4日からはすべてのブランド案件をRobloxに登録し、アセットのモデレーション審査を受けることが義務化される。

### Shopify連携とコマースAPI

**2025年5月15日**にShopifyとのコマース統合が開始され、エクスペリエンス内での物理商品の直接販売が可能になった。米国の13歳以上のユーザーが対象で、Fenty BeautyやThe Weekndなどのブランドがショッパブルエクスペリエンスを展開した。さらにApproved Merchandiser Program（AMP）が導入され、小売購入とRoblox上のデジタルアバターアイテムの連携も実現した。

### クリエイター収益の推移

クリエイターの年間収益は2024年の**$922.8M**から2025年の**$1,503.1M**へと約63%増加し、初めて10億ドルの大台を突破した。DevExプログラムの参加者は35,500人以上に拡大し、トップ1,000クリエイターの平均収益は$1.3M（2025年）であった。

## 4. コミュニティ・プラットフォーム：年齢確認の義務化と安全対策の大転換

### 顔年齢推定によるチャット年齢確認の世界的義務化

この期間中で最もインパクトの大きいプラットフォーム変更は、**チャット機能へのアクセスに顔年齢推定を義務化**した決定である。2025年7月17日にPersona社の技術を用いた13歳以上向けのFacial Age Estimationが開始され、2025年9月に全ユーザーへの拡大が発表された。2025年11月18日に具体的な導入計画が公開され、6つの年齢グループ（**9歳未満、9-12歳、13-15歳、16-17歳、18-20歳、21歳以上**）が設定された。

- **大人と16歳未満の子供間のチャットはデフォルトでブロック**
- 9歳未満のチャットは保護者の同意がない限りデフォルト無効
- 2025年12月初旬にオーストラリア、ニュージーランド、オランダで先行義務化
- **2026年1月7日にグローバル義務化**が完了

オンラインゲームプラットフォームとして初めてこの規模の年齢確認を義務化した事例とされている。

### ソーシャル機能の大改編：FriendsからConnectionsへ

**2025年7月17日**に、「Friends」が「**Connections**」に改称され、同時に「**Trusted Connections**」（実生活で知り合いの相手とのつながり）が導入された。Trusted Connections相手にはフィルタリングされない表現力豊かなチャットが可能となり、Connection上限は200から**1,000**に引き上げられた。13-17歳のティーンが成人とTrusted Connectionsを作成するにはQRコードまたは連絡先インポートによる認証が必要である。

### Groups → Communities への移行とGuildedの終了

2024年末にRoblox Groupsが**Roblox Communities**にリブランドされた。Community Forumsが2025年8月21日に正式ローンチし、従来のCommunity Wallsは2025年12月に読み取り専用となり、2026年3月末に完全削除が予定された。Robloxが2021年に買収した**Guildedは2025年12月19日にシャットダウン**され、すべてのコンテンツが利用不能になった。これに伴いCommunity AnnouncementsがGuildedの代替として導入され、Community Cover Photos（バナー）や**複数ロールの同時付与**（2026年3月）も追加された。

### コンテンツポリシーの大幅強化

2025年を通じて安全ポリシーが段階的に強化された。主要な変更は以下の通り。

- **2025年8月**：暗示的な性的コンテンツの明示的禁止（アバターの体、衣装、エモート等）、プライベート空間（寝室・浴室）を含むソーシャルハングアウトの17+制限、バー・クラブ等の大人向け設定の17+制限
- **2025年8月11日**：「Sensitive Issues」コンテンツディスクリプタの追加（デリケートな社会・政治・宗教トピックのタグ付け）
- **2025年9月3日**：**IARC（国際年齢評価連合）とのパートナーシップ**が発表され、Roblox独自のコンテンツ成熟度ラベルが地域別のレーティング（ESRB、PEGI、GRAC、USK等）に置き換えられる
- **2025年9月30日**：未レーティングのエクスペリエンスがプレイ不能に（Content Maturity & Compliance Questionnaireの未完了分）
- **2025年11月6日**：Restricted（制限付き）コンテンツの年齢要件を17+から**18+に引き上げ**
- **2025年12月17日**：公開エクスペリエンスの公開/更新に新要件を追加（ID認証、2025年以降の実通貨購入、または一定のプレイ実績のいずれかが必要）

Robloxは2025年1月以降に**145以上の安全イニシアチブ**を出荷し、2025年8月にはチャット内の児童グルーミングを検出するAIシステム**Roblox Sentinel**をオープンソース化した（日次60億メッセージを分析、2025年上半期にNCMECへ約1,200件の報告を提出）。

### Creator Hub の刷新とアクセシビリティ

**2026年3月**にCreator Hubが大幅リニューアルされ、エクスペリエンス・ページ・ドキュメントの横断検索、フィルタリング可能なプロダクトアップデートのchangelogページ、エクスペリエンスタイル付きの再デザインされたホーム画面が導入された。

アクセシビリティでは、**2025年8月27日にグローバルテキストサイズ設定**が全Robloxゲームで有効化され、プレイヤーは「large」「larger」「largest」を選択できるようになった。2025年10月には「**Roblox Everywhere**」イニシアチブによりスマートTVやウェアラブルディスプレイへの拡張が行われ、クロスデバイスでの進捗・購入・クラウドセーブの同期が実現した。

### RDC 2025の概要

2025年9月5-6日にサンノゼで開催されたRDC 2025では、本レポートで触れた多くの機能が発表された。特筆すべき追加発表として、**Roblox Moments**（ゲームプレイのショートフォーム動画共有機能、タップで即座にエクスペリエンスに参加可能）、**リアルタイム音声チャット翻訳**、**ライセンスカタログの拡張**（Lionsgate、Netflix、Sega、講談社等との提携）、サンパウロデータセンターの完全稼働が挙げられる。

## 結論：プラットフォーム成熟の加速と開発者への示唆

2024年12月から2026年3月にかけてのRobloxは、「ゲームプラットフォーム」から**「フルスタックのクリエイターエコシステム」**への変容を明確に推し進めた。エンジン面ではSLIM・Texture Streaming・Unified Lightingの三位一体が「Wait, that's Roblox?」と言われるビジュアル品質を技術的に可能にし、スクリプト面ではServer Authorityとluauの型システム成熟がゲーム品質の底上げを支える。AIツール群の進化速度は特に目覚ましく、2025年3月のテキストtoメッシュから2026年3月のネイティブMCPと自動プレイテストまで、わずか1年でAIアシスタントが「コード補助」から「自律的な開発パートナー」へ進化した。

経済面では、DevExレート引き上げ・Creator Rewards・法定通貨Paid Access・Regional Pricingの4つの施策がクリエイター収益を2024年比63%増に押し上げた一方、2027年からのブランドインテグレーション収益シェアは独立系クリエイターのビジネスモデルに大きな影響を与えうる。安全面での年齢確認義務化とIARC連携は、規制当局やメディアからの圧力に対する先手の対応であり、開発者にとってはContent Maturity Questionnaireの完了やチャット依存ゲームメカニクスの再設計が必須のアクションとなっている。

ソロ開発者にとっては、AIアシスタントの進化とMCPによる外部ツール連携が生産性を大幅に引き上げるチャンスである一方、チーム開発者にとってはServer Authorityへの移行計画とブランドインテグレーションポリシーへの対応が2026年の最優先課題となるだろう。
